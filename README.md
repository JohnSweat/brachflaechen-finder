# Brachflächen-Finder

Karte zum Aufspüren verwilderter Grundstücke in Österreich: Luftbild (aktuell und früher), Kataster, INVEKOS, Agraratlas, Hochwasser.

Seite öffnen: https://johnsweat.github.io/brachflaechen-finder/

Alle Daten ohne Gewähr. Quellen: basemap.at, BEV, Agrarmarkt Austria, BMLUK (Agraratlas), Umweltbundesamt, Esri World Imagery Wayback, OpenStreetMap (Ortssuche über Nominatim; Bahnhöfe, Haltestellen und Wald über OpenFreeMap / OpenMapTiles).
