# Brachflächen-Finder

Karte zum Aufspüren verwilderter Grundstücke in Österreich: Luftbild (aktuell und früher), Kataster, INVEKOS, Agraratlas, Hochwasser. In Wien zusätzlich Öffis, E-Laden, Carsharing, Leihrad, Taxi, Rad, Parken, Baustellen, Planungen, Flächenwidmung, Bauverfahren, Kraftwerke und Industrieflächen. Für ganz Österreich Lärmkarten und Breitband.

Seite öffnen: https://johnsweat.github.io/brachflaechen-finder/

Am Handy: Seite über den Link öffnen und im Browsermenü „Zum Startbildschirm hinzufügen“ wählen. Eine heruntergeladene Datei ist eine alte Kopie; dort fehlen Grundstücksdaten und Kopieren.

Alle Daten ohne Gewähr. Quellen: basemap.at, BEV, Agrarmarkt Austria, BMLUK (Agraratlas), Umweltbundesamt, Esri World Imagery Wayback, OpenStreetMap (Ortssuche und Adressen über Nominatim; Bahnhöfe, Haltestellen und Wald über OpenFreeMap / OpenMapTiles), Stadt Wien – data.wien.gv.at (Öffi-Netz, Mobilität, Rad, Parken, Planungen, Widmung, Realnutzung, Energieanlagen, Luftbilder), WienMobil Rad über den GBFS-Feed von nextbike (CC0), Lärmkarten über inspire.gv.at, Breitbandatlas (breitbandatlas.gv.at).
