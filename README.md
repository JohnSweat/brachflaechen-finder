# Brachflächen-Finder

Karte zum Aufspüren verwilderter Grundstücke in Österreich: Luftbild (aktuell und früher), Kataster, INVEKOS, Agraratlas, Hochwasser.

Seite öffnen: https://johnsweat.github.io/brachflaechen-finder/

Alle Daten ohne Gewähr. Quellen: basemap.at, BEV, Agrarmarkt Austria, BMLUK, Umweltbundesamt, Esri, OpenStreetMap.
